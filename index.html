Bundled vs. Add-On Map

What's already inside each package — and what you can legitimately stack on top

Each primary ablation and implant code is a package: the comprehensive study, mapping, and pacing components baked into the base code cannot be billed again. The revenue lever is knowing which components fall outside the package and are separately reportable as add-ons. The classic trap — ICE (93662) is bundled into AFib PVI (93656) but separately billable with SVT (93653) and VT (93654).

✕ Bundled — included in the base code, do not bill separately + Separately billable add-on when performed & documented
93650AV Node Ablation9.98 wRVU

✕ Bundled / not allowed

  • 93623IV-drug stim — not reportable with 93650
  • —Ablation, catheter placement, fluoro

+ Separately billable

  • 93600His recording · standard add-on (+2.07)
  • 93610/02Atrial pacing/recording · only if performed & documented
Gotcha: Unlike 93653/54/56, 93650 carries no comprehensive-study package, so diagnostic components aren't auto-bundled — His recording (93600-26) is the standard add-on. But 3D mapping (93613) is rarely justifiable for an AV-node ablation (audit red flag) — skip it without clear necessity. Never append 93623, and don't bill a full study (93620) plus individual components.

Universal rules that override the cards

  • One primary ablation package per case. 93653 / 93654 / 93656 are mutually exclusive — each includes a full diagnostic study. A second distinct mechanism is +93655, never a second primary code.
  • Ultrasound guidance is always bundled. Vascular-access US (76937) and other US guidance (76942, 76998, 93318) are bundled into 93600–93662 per CCI — never separately billable during an EP procedure.
  • 93623 has a purpose limit. Per CCI, report IV-drug programmed stim only for diagnostic stimulation — not for confirming ablation adequacy after ablation. Not reportable with 93650.
  • MUE caps on the AFib add-ons. 93655 = 2 units and 93657 = 2 units. Documenting 3 total distinct mechanisms supports 93655 ×2; 93657 bills only with 93656.
  • Origin mapping (93609) is once per case. A single unit covers all sites mapped — it does not stack like 93655. Reportable only with 93653 (SVT/flutter) and 93656 (AFib); it is bundled into 93654 because localizing the VT focus is inherent to the code.

Key Insights

  • 01
    AFib ablation has the highest single-encounter ceiling. A complex AF + flutter + SVT case can clear ~39 wRVU — more than 2× a clean PVI. Documentation of distinct mechanisms (93655) and remaining triggers post-PVI (93657) is the lever.
  • 02
    VT ablation has the highest per-code base. 93654 (17.65) > 93656 (16.58) > 93653 (14.63). 93656 catches up quickly with add-ons because PVI cases more often have multiple foci.
  • 03
    Lead extraction is the highest-RVU implant-side procedure. 33243/33244 at 15–16 wRVU outpaces an ICD generator change (5–8 wRVU) by 2–3×. If your group is doing extractions, capture is essential.
  • 04
    ICE (93662) and IV-drug stim (93623) are the cheapest "free" boosts — 1.40 and 0.96 respectively when clinically performed and documented. Easy capture targets on the audit side.
  • 05
    Remote monitoring favors the ILR. An ILR generates 0.52 wRVU every 30 days vs. 0.55–0.74 every 90 days for PPM/ICD — roughly 3× the annualized wRVU per device.
  • 06
    Programming bundles interrogation. 93279–93284 (programming) and 93288/93289 (in-person interrog.) cannot be billed same day — programming wins. Track this in your monthly billing audit.
  • 07
    G2211 + 99214/99215 is a quiet win. Adding 0.33 wRVU per qualifying complex E/M visit compounds across the year. Continue capturing this.
  • 08
    Critical care (99291) at 4.50 wRVU outpaces the highest inpt initial visit (99223, 3.50). When you're truly providing critical care for >30 min — for example, a peri-ablation hemodynamic crisis or post-implant tamponade — code it as such. Documentation must support it.
  • 09
    Commercial consult codes still pay. 99245 / 99255 (3.50–4.00 wRVU) outpace 99205 / 99223 (3.50). For commercial payers that still reimburse 992xx consults, capturing the consult code rather than the new-patient or initial inpt code adds 0.50 wRVU per qualifying encounter.
  • 10
    Same-day admit/discharge (99236) at 4.00 wRVU outpaces a standard initial-visit + discharge combo (99223 + 99238 = 4.78, but only when separate days are documented). Use 99234–99236 when admission and discharge truly fall on one calendar day; otherwise the split-billing pathway wins.
